### Purpose of repository

Code used to analyze the methylation components of snmCT-seq/snm3C-seq in Li et al. 2026.

Versions:
- ALLCools 1.0.5 [https://lhqing.github.io/ALLCools/intro.html](url) - used for handling methylation files, including generation of CpG-level methylation estimates, dimensionality reduction, and pseudobulk aggregation
- leidenalg 0.10.2 [https://github.com/vtraag/leidenalg](url)
- Harmony 0.0.10 [https://github.com/immunogenomics/harmony](url)
- Scanpy 1.10.0 [https://github.com/scverse/scanpy](url) - used to call DEGs in specific contexts - Start vs. Fail1, IPS-SE vs. IPS-LE
